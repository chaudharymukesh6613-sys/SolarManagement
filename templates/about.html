About Solar Management System

Project Overview

The Solar Management System is a web-based application developed as a BCA Final Year Project. It helps manage customer records, solar panel details, installations, billing, and reports efficiently.


Project Objective

The main objective of this project is to simplify solar service management, reduce paperwork, improve data accuracy and provide quick access to customer information.


Features

  • ✔ Customer Management
  • ✔ Solar Panel Management
  • ✔ Installation Management
  • ✔ Billing System
  • ✔ Report Generation
  • ✔ Dashboard

Technologies Used

  • 🐍 Python
  • ⚡ Flask
  • 🌐 HTML
  • 🎨 CSS
  • 🗄 SQLite
